## Overview

**SMART — BRMP SDLAHAN** adalah aplikasi berbasis web yang dikembangkan untuk mendukung proses monitoring, analisis, reporting, dan tracking terhadap realisasi capaian serta anggaran kegiatan pada satuan kerja BRMP SDLAHAN, Kementerian Pertanian Republik Indonesia.

Sistem dirancang untuk menyajikan informasi kegiatan dan anggaran secara terstruktur sehingga proses pemantauan, evaluasi, dan pelaporan dapat dilakukan secara lebih efektif.

## Getting Started

### Requirements

Pastikan environment berikut telah tersedia:

* Node.js 18 atau versi terbaru
* npm

### Installation

Clone repository:

```bash
git clone https://github.com/USERNAME/REPOSITORY.git
cd REPOSITORY
```

Install dependencies:

```bash
npm install
```

Jalankan development server:

```bash
npm run dev
```

Aplikasi dapat diakses melalui:

```text
http://localhost:3000
```

## Purpose

SMART dikembangkan sebagai bagian dari upaya digitalisasi proses monitoring dan pengelolaan informasi kegiatan pada lingkungan BRMP SDLAHAN.

Sistem ini berfokus pada:

* Monitoring realisasi kegiatan
* Monitoring penggunaan anggaran
* Analisis capaian
* Tracking progres kegiatan
* Penyajian informasi secara terpusat
* Mendukung proses evaluasi dan pelaporan
